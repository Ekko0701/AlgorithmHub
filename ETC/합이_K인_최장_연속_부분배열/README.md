# 합이 K인 최장 연속 부분배열

## 문제

정수 배열 A(음수 포함 가능)에서, 합이 정확히 K가 되는 연속 부분배열의 **최대 길이**를 구하세요.
그런 부분배열이 없으면 0을 출력합니다.

## 입력

```
N K
A1 A2 ... AN
```

## 출력

```
합이 K인 연속 부분배열의 최대 길이
```

## 제한

- 1 ≤ N ≤ 200,000
- -10⁹ ≤ Aᵢ ≤ 10⁹
- -10¹⁴ ≤ K ≤ 10¹⁴

## 예시

### 입력
```
8 5
1 -1 5 -2 3 2 -2 2
```

### 출력
```
6
```

### 설명
`[-1, 5, -2, 3, 2, -2]` (인덱스 1~6)의 합이 5, 길이 6.
